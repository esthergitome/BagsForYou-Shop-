# Online Shop (WordPress + WooCommerce)

An online shop I set up and customised using WordPress, WooCommerce, a ready-made theme and plugins. This project shows my work in site setup, product management and page design, without custom code.

## What I Did

- Installed and configured WordPress on a local Fedora Linux server (Apache, PHP, MariaDB)
- Set up WooCommerce and added products with categories, prices and images
- Customised the theme: homepage layout, menus, colours and pages (About Us, Contact)
- Installed and configured plugins
- Made the site available online for demos using ngrok
